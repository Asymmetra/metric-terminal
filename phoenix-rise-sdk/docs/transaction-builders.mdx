title: "Transaction Builders"

Transaction builders construct Solana instructions for interacting with the Phoenix protocol. Use them to build custom transactions for order placement, cancellations, deposits, withdrawals, and trader management.

## Building Instructions

All builders follow a consistent pattern:

```typescript
import {
  buildPlaceMarketOrderIx,
  buildPlaceLimitOrderIx,
  buildCancelOrdersByIdIx,
  type PlaceMarketOrderIx,
} from 'phoenix-sdk';

const instruction: PlaceMarketOrderIx = await buildPlaceMarketOrderIx({
  authority: 'YOUR_WALLET_ADDRESS',
  symbol: 'SOL',
  side: 'Bid',
  baseLots: 100n,
  client: {
    // See below for client interface
  },
});
```

## Order Instructions

### Market Orders

```typescript
const ix = await buildPlaceMarketOrderIx({
  authority: 'YOUR_AUTHORITY',
  symbol: 'SOL',
  side: 'Bid',        // 'Bid' or 'Ask'
  baseLots: 100n,
  maxQuoteLots?: undefined,  // No slippage limit
  traderPdaIndex?: 0,
  client,
});
```

**Parameters:**
- `authority: Address` - Trader's wallet address (must be signer)
- `symbol: string` - Market symbol (e.g., "SOL", "ETH")
- `side: 'Bid' | 'Ask'` - Order side
- `baseLots: bigint` - Order size in base lots
- `maxQuoteLots?: bigint` - Maximum quote lots for slippage protection
- `traderPdaIndex?: number` - Trader PDA index (default: 0)

**Returns:** `PlaceMarketOrderIx` instruction

### Limit Orders

```typescript
const ix = await buildPlaceLimitOrderIx({
  authority: 'YOUR_AUTHORITY',
  symbol: 'SOL',
  side: 'Bid',
  price: ticks(150.50),    // Price in ticks
  baseLots: 100n,
  orderType?: 'Good',      // 'Good' (GTC) or 'Immediate' (IOC)
  selfTradeBehavior?: 'Abort',
  useOnlyDepositedCollateral?: false,
  traderPdaIndex?: 0,
  client,
});
```

**Parameters:**
- `authority: Address` - Trader's wallet address
- `symbol: string` - Market symbol
- `side: 'Bid' | 'Ask'` - Order side
- `price: Ticks` - Limit price (use `ticks()` helper)
- `baseLots: bigint` - Order size
- `orderType?: 'Good' | 'Immediate'` - GTC or IOC
- `selfTradeBehavior?: 'Abort' | 'CancelNewest' | 'CancelOldest'` - Self-trade handling
- `useOnlyDepositedCollateral?: boolean` - Reject if insufficient margin

**Returns:** `PlaceLimitOrderIx` instruction

### Post-Only Orders

```typescript
const ix = await buildPlacePostOnlyOrderIx({
  authority: 'YOUR_AUTHORITY',
  symbol: 'SOL',
  side: 'Bid',
  price: ticks(150.50),
  baseLots: 100n,
  rejectOnInsufficientMargin?: false,
  traderPdaIndex?: 0,
  client,
});
```

Orders are automatically rejected if they would cross the spread (post-only constraint).

### Stop-Loss Orders

```typescript
const ix = await buildPlaceStopLossIx({
  authority: 'YOUR_AUTHORITY',
  symbol: 'SOL',
  triggerPrice: ticks(145.00),
  side: 'Ask',              // Side to exit position
  baseLots: 100n,
  orderType?: 'Good',
  client,
});
```

Automatically triggers a market order when the mark price crosses the trigger level.

## Cancellation Instructions

### Cancel by Order ID

```typescript
const ix = await buildCancelOrdersByIdIx({
  authority: 'YOUR_AUTHORITY',
  symbol: 'SOL',
  orderIds: ['order_id_1', 'order_id_2'],
  traderPdaIndex?: 0,
  client,
});
```

**Parameters:**
- `authority: Address` - Trader's wallet
- `symbol: string` - Market symbol
- `orderIds: string[]` - List of order IDs to cancel
- `traderPdaIndex?: number` - Trader PDA index

### Cancel All Orders

```typescript
const ix = await buildCancelAllIx({
  authority: 'YOUR_AUTHORITY',
  symbol: 'SOL',
  traderPdaIndex?: 0,
  client,
});
```

Cancels all orders in the specified market.

### Cancel Stop-Loss

```typescript
const ix = await buildCancelStopLossIx({
  authority: 'YOUR_AUTHORITY',
  symbol: 'SOL',
  triggerPrice: ticks(145.00),
  client,
});
```

Cancels stop-loss orders at a specific trigger price.

## Deposit & Withdrawal Instructions

### Deposit Funds

```typescript
const ix = await buildDepositFundsIx({
  authority: 'YOUR_AUTHORITY',
  amount: 1000n,          // Amount in USDC atomic units (6 decimals)
  traderPdaIndex?: 0,
  client,
});
```

Deposits USDC from your wallet into Phoenix protocol. Returns a single instruction.

### Deposit Flow (Multi-step)

```typescript
const { instructions, named } = await depositFlow({
  authority: 'YOUR_AUTHORITY',
  amount: 1000n,           // USDC amount
  traderPdaIndex?: 0,
  client,
});

// instructions: [createAta, emberDeposit, depositFunds]
// named: { createAta, emberDeposit, depositFunds }
```

Composable flow that:
1. Creates ATA for Phoenix tokens (idempotent)
2. Deposits USDC to Ember to receive Phoenix tokens
3. Deposits Phoenix tokens into Phoenix protocol

### Withdraw Funds

```typescript
const ix = await buildWithdrawFundsIx({
  authority: 'YOUR_AUTHORITY',
  amount: 1000n,          // Amount in USDC
  traderPdaIndex?: 0,
  client,
});
```

Initiates withdrawal from Phoenix protocol.

### Withdraw Flow (Multi-step)

```typescript
const { instructions, named } = await withdrawFlow({
  authority: 'YOUR_AUTHORITY',
  amount: 1000n,
  traderPdaIndex?: 0,
  client,
});

// Returns instructions for withdrawal with token wrapping
```

Composable flow that:
1. Approves Ember to spend Phoenix tokens
2. Withdraws Phoenix tokens from protocol
3. Converts Phoenix tokens back to USDC via Ember

## Trader Management

### Register Trader

```typescript
const ix = await buildRegisterTraderIx({
  authority: 'YOUR_AUTHORITY',
  maxPositions?: 20,
  client,
});
```

Creates a new trader account and initializes position tracking.

### Register Subaccount

```typescript
const ix = await buildRegisterTraderIx({
  authority: 'YOUR_AUTHORITY',
  subaccountIndex: 1,
  maxPositions?: 20,
  marginType: 'Isolated',
  client,
});
```

Creates an isolated margin subaccount for the trader.

### Delegate Trader

```typescript
const ix = await buildDelegateTraderIx({
  authority: 'YOUR_AUTHORITY',
  delegate: 'DELEGATE_PUBKEY',
  permissions: 0n,        // Permission bitmask
  client,
});
```

Grants delegation rights to another address.

## Collateral Management

### Transfer Collateral

```typescript
const ix = await buildTransferCollateralChildToParentIx({
  authority: 'YOUR_AUTHORITY',
  fromSubaccountIndex: 1,
  toSubaccountIndex: 0,
  amount: 500n,
  client,
});
```

Transfers collateral from isolated subaccount to main account.

### Sync Parent to Child

```typescript
const ix = await buildSyncParentToChildIx({
  authority: 'YOUR_AUTHORITY',
  sourceSubaccountIndex: 0,
  targetSubaccountIndex: 1,
  client,
});
```

Syncs parent trader state to isolated child subaccount.

## Client Interface

All builders require a client implementation:

```typescript
interface PhoenixInstructionClient {
  address: Address;
  network: 'mainnet' | 'devnet';
  
  // Fetch accounts needed for instruction building
  getAccount(address: Address): Promise<Account | null>;
  
  // Fetch multiple accounts
  getAccounts(addresses: Address[]): Promise<(Account | null)[]>;
}
```

## Price Conversion Helper

Convert USD prices to ticks:

```typescript
import { ticks } from 'phoenix-sdk';

const priceTicks = ticks(150.50);  // $150.50 → ticks value
```

## Instruction Types

Each builder returns a typed instruction:

```typescript
interface PlaceMarketOrderIx {
  ix: Instruction;
  data: {
    authority: Address;
    symbol: string;
    side: Side;
    baseLots: bigint;
  };
}
```

Access the raw instruction via `.ix`, or the metadata via destructuring.

## Error Handling

```typescript
try {
  const ix = await buildPlaceMarketOrderIx({
    authority,
    symbol: 'SOL',
    side: 'Bid',
    baseLots: 100n,
    client,
  });
} catch (error) {
  if (error instanceof PhoenixBuilderError) {
    console.error(`Builder error: ${error.message}`);
  }
}
```

## Notes

- All amounts are in atomic units (base/quote lots, USDC with 6 decimals)
- Prices are converted to ticks using the `ticks()` helper
- Instructions must be sent in the same transaction (except where noted as individual)
- Multi-step flows (deposit, withdraw) return multiple instructions to be batched
- Signers are inferred from instruction context; ensure the authority has signing capability
